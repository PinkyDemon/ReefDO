Normal is silent; ack and maintenance mute everything. LED codes are fixed: green steady = OK online, green 0.5 Hz = OK offline, blue 1 Hz / yellow 2 Hz / red 4 Hz = alert, purple 2 Hz = FAULT, cyan = maintenance, white pulse = service run.

Maintenance mode

Mutes the buzzer and enables the tests below for 30 min. The ladder keeps running; level-driven devices still win.

Relay test

Forces the device on for 5 s, then back to automatic. Check the device — and the multimeter on COM/NO/NC the first time.
